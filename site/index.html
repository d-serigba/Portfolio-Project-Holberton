About

Holberton Games is a web application designed to compile a collection of retro games developed as part of the C29 cohort portfolio project, the primary objective is to build a complete, functional gaming platform that integrates gameplay directly into the browser that can handles registration, login and scores and a hub that lists the available games. Each game opens as a Pygame window already connected to the player's account.

Tech stack

Frontend

  • HTML / CSS / JavaScript: web interface and calls to the API

Backend and tools

  • Python 3.12: core language
  • Flask: backend framework
  • Pygame: game engine
  • SQLite and SQLAlchemy: local database and ORM
  • MySQL (PyMySQL): optional storage
  • Flask-JWT-Extended: user authentication
  • Flask-CORS: frontend and backend communication

Run it locally

The games are Pygame desktop windows and the API is a Flask server, so the platform runs on your machine, not on this page. The launcher targets Windows 10 / 11.

  1. Install Python 3.12 with the py launcher, and Git.
  2. Clone the project and install the dependencies:
git clone https://github.com/d-serigba/Portfolio-Project-Holberton.git
cd Portfolio-Project-Holberton
py -3.12 -m pip install -r docs/api/requirements.txt
  1. Double-click launch_hub.bat at the root of the project.
  2. Open http://127.0.0.1:5000 in your browser, create an account and pick a game.

Read the full README for troubleshooting.
