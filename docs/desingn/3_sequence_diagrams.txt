SEQUENCE DIAGRAMS

1. MOVEMENT

Input (Q/D)
→ Player.move()
→ Collision check (Zone)
→ Position update
→ Render frame

2. ATTACK

Input (X/K)
→ Player.attack()
→ Create hitbox
→ Check enemy collision
→ Apply damage
→ Enemy dies or survives

3. ZONE CHANGE

Player touches exit
→ Facade detects collision
→ Zone Manager loads new zone
→ Player spawn updated
→ New zone rendered
