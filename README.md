# Holberton Games - Portfolio Project C28

## Project Objective

Holberton Games is a web application designed to compile a collection of retro games. Developed as part of the C28 cohort portfolio project, the primary objective is to build a complete, functional web platform that integrates gameplay directly into the browser.

## Team

  - **David Dufont**: Backend Developer
  - **Dylan Serigba**: Frontend Developer

## Games Included

The project features a selection of games inspired by various classics:

  - **"Arnaud’s Bizarre Adventure"**: A Zelda-like adventure game.
  - **Metroidvania**: An exploration game inspired by the classics, Metroid and Castlevania.
  - **Versus Fighting**: A combat game inspired by fighting classics.
  - **Hotline Miami Clone**: A top-down action game.

## Tech Stack

### Frontend

  - **HTML**: Used to structure web page content.
  - **CSS**: Used for styling and layout.
  - **JavaScript**: Used for interactivity and managing API calls to the backend.

### Backend & Tools

  - **Python**: Core programming language.
  - **Pygame**: Graphic design and game engine.
  - **Flask**: Backend framework.
  - **MySQL**: Data storage.
  - **SQLite & SQLAlchemy**: Local database management and ORM for data manipulation.
  - **JWT (JSON Web Token)**: User security and authentication.
  - **CORS**: Enables communication between the frontend and backend on different ports.

## Requirements

To install the project dependencies, ensure you have Python configured, then use a `requirements.txt` file with the following content:

``` text
Flask==3.0.2
Flask-SQLAlchemy==3.1.1
Flask-JWT-Extended==4.6.0
PyMySQL==1.1.0
cryptography==42.0.5
pygame==2.6.1
requests==2.31.0

```

**Quick Installation:**
`pip install -r requirements.txt`
